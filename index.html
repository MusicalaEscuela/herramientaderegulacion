🌬️ Respiración guiada

Para ansiedad, miedo, llanto o respiración rápida. Ideal de 4 a 12 años.

Huele una flor

Guion para la profe

“No tienes que hacerlo perfecto. Mira mi respiración. Huele una flor… ahora sopla una vela. Otra vez, suavecito.”

🧭 Grounding 5-4-3-2-1

Para volver al presente cuando hay bloqueo, miedo o sensación de perder el control.

  1. 5 cosas que pueda ver
  2. 4 cosas que pueda tocar
  3. 3 sonidos suaves que pueda notar
  4. 2 olores o sensaciones
  5. 1 frase segura: “Estoy aquí y estoy a salvo”

🎧 Sobrecarga por ruido

Cuando el detonante sea volumen, gritos, eco, parlantes o muchos niños hablando a la vez.

🧸 Trabajo pesado suave

Para niños inquietos, saturados o con energía desbordada. Siempre como juego, nunca como castigo.

💪 Empujar la pared 10 seg 🛋️ Apretar un cojín 📦 Llevar una caja liviana 🧸 Abrazar un peluche grande 🌯 Enrollarse en una manta

Semáforo de actuación

Para saber qué tan grave es la situación y qué hacer, de un vistazo.

Verde · Acompañar

Llanto leve, se comunica, acepta respirar o sentarse, baja con pausa.

👉 Pausa, agua, validación, regreso gradual.

Amarillo · Avisar internamente

Llanto intenso, miedo persistente, no quiere volver, se tapa oídos, necesita mucho tiempo.

👉 Adulta referente, informar a coordinación y familia.

Rojo · Apoyo inmediato

Dificultad para respirar, desmayo, dolor fuerte, vómito, desorientación, autolesión, intento de fuga o no logra calmarse.

👉 Llamar acudiente, coordinación y atención médica si hay riesgo físico.

Frases listas

Toca cualquier tarjeta para copiar y usar la frase tal cual.

🧒 Para el niño o niña

“Te creo. El ruido se sintió muy fuerte para ti. Estás segura/o. No tienes que explicarme todo ahora. Vamos a ayudar a tu cuerpo a calmarse.”

📋 Tocar para copiar

👥 Para el grupo

“Vamos a bajar un poquito el volumen. A veces el ruido puede sentirse muy fuerte para algunas personas. Seguimos la actividad con cuidado.”

📋 Tocar para copiar

👨‍👩‍👧 Para la familia

“Hola, queremos contarles que hoy tuvo un momento de ansiedad asociado al ruido. La acompañamos a un espacio tranquilo, hizo una pausa y estamos observando cómo evoluciona…”

📋 Tocar para copiar

📋 Para coordinación

“Se presentó episodio de ansiedad/sobrecarga sensorial. Detonante reportado: ruido. Se retiró del estímulo, se acompañó con regulación…”

📋 Tocar para copiar

🌱 Principios de uso

  • 💜 Validar primero, explicar después.
  • 🧍 Una sola persona adulta acompaña; muchas miradas aumentan la crisis.
  • 🤫 Menos palabras, más calma corporal.
  • 🎯 El objetivo no es que “se porte bien”, es que vuelva a sentirse segura/o.
  • 🚨 Si hay riesgo físico o síntomas intensos, se activa familia y apoyo médico.

Versión interna Musicala. Esta guía no reemplaza evaluación clínica ni atención de urgencias cuando hay riesgo físico o emocional alto.
